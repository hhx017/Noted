# Changelog

All notable changes to Noted BuJo (Windows) are documented here.

## [1.0.0] - 2026-08-21

### Added
- Dashboard with global search (tasks, appointments, topics), upcoming appointments, and daily habit check-off.
- Year plan with holidays, days off school, exams/deadlines management.
- Month plan with calendar overview, goals, and reflection.
- Week plan with input/self-study phases, module topics with day assignment, private appointments, reflection, and task migration.
- Day plan with Bullet Journal status symbols (open / done / migrated / discarded).
- Timetable (8 × 5 grid) with subject, room, and teacher per slot.
- Habit tracker with weekly grid, custom colors, and optional time windows.
- Subject manager with colors, teachers, and module lists.
- Automatic index with page numbers.
- Full-year PDF export: cover page with profile, table of contents, timetable, year overview, week plans, and monthly habit grids — with configurable title, colors, section toggles, and a sample-data preview mode.
- Light / dark / system themes.
- Local data storage (SQLite), license activation gate.
